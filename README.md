# 🚗 Plataforma Web de Alquiler de Vehículos

Aplicación web interactiva para la gestión y reserva de vehículos de alquiler, desarrollada con una arquitectura desacoplada entre un frontend en **React** y un backend en **Spring Boot**.

---

## 📌 Visión General del Proyecto

El sistema está diseñado para dar soporte a dos tipos de usuarios principales:

* 👤 **Clientes:** Explorar la flota de vehículos disponible, visualizar galerías detalladas de fotos, consultar precios, filtrar por categorías y realizar reservas de alquiler.
* 🛠️ **Administradores:** Gestionar el inventario de la flota (altas, bajas y modificaciones de vehículos), administrar galerías de imágenes y supervisar el estado de las reservas.

---

## 🛠️ Stack Tecnológico

* **Frontend:** React, React Router, Custom Hooks, Axios, CSS3 (Modules & Flexbox/Grid).
* **Backend:** Java (Spring Boot), Spring Data JPA / Hibernate, RESTful API.
* **Base de Datos:** Relacional (MySQL / PostgreSQL).
